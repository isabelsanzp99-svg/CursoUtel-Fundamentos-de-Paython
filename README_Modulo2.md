# Proyecto Final - Módulo 2: Validación y Operaciones de Datos

## Descripción de los Programas
El archivo contiene la solución a dos retos utilizando estructuras de control de flujo y validaciones:

1. **Longitud de una palabra:** Programa que evalúa la cantidad de caracteres ingresados por el usuario mediante la
   función `len()`. Utiliza estructuras condicionales (`if`, `elif`, `else`) para validar si la palabra se encuentra en el
   rango de 4 a 8 letras, o si por el contrario le faltan o le sobran caracteres, imprimiendo un mensaje personalizado en cada caso.
3. **Encuentra el cuadrante:** Programa basado en el Plano Cartesiano que solicita las coordenadas X y Y. Primero verifica
   que ninguna de las dos sea igual a cero y posteriormente evalúa las combinaciones de signos para determinar con exactitud
   a cuál de los cuatro cuadrantes (I, II, III o IV) pertenece el punto ingresado.
